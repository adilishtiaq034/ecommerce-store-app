# Ecommerce App

A modern ecommerce frontend built with React featuring products browsing, category filtering, shopping cart functionality, and a responsive user interface.

##  Features

- Product listing
- Shopping cart
- Add & remove items
- Quantity management
- Responsive design
- Modern UI
- React Context API
- Fast performance
